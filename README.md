# TrackMyFinance 💰💎

**TrackMyFinance** — це сучасний, високопродуктивний вебзастосунок для комплексного управління особистими фінансами, побудований на стеку **Next.js 14 (App Router)**, **React 18** та **TypeScript**.

Застосунок поєднує зручний облік щоденних доходів і витрат, планування майбутніх платежів, контроль комунальних послуг, облік боргів, а також багаторівневу систему персоналізації профілю з VIP-підписками.

---

## ✨ Основні можливості

### 1. 🏠 Повний облік доходів та витрат (Головна)
- **Миттєве додавання (Inline Quick Add)**: швидке введення суми, категорії та коментаря без зайвих вікон.
- **Розумна валідація чисел**: підтримка роздільників коми та крапки (`250`, `450,50`, `450.50`).
- **Фільтрація та аналітика**: перегляд усіх операцій, тільки витрат або тільки доходів із підрахунком чистого балансу.

### 2. 📅 Список планованих платежів (`/planned`)
- Планування регулярних оплат (підписки, кредити, оренда).
- Відстеження дат і дедлайнів.
- Переведення у статус «Сплачено» в 1 клік із можливістю автоматичного запису у витрати.

### 3. 💡 Комунальні платежі (`/utilities`)
- Облік витрат на світло, газ, воду, тепло, інтернет та ЖКП.
- Введення показників лічильників, розрахунок суми та статус оплати.

### 4. 🤝 Облік боргів та позик (`/debts`)
- Розподіл на дві категорії: **«Мені винні»** та **«Я винен»**.
- Фіксація імені контрагента, суми, дати та статусу закриття боргу.

## 🎨 Персоналізація та VIP-система

- **Зміна нікнейму**: можливість встановити будь-яке власне ім'я в налаштуваннях профілю.
- **Значок Delux у нікнеймі**: статусний сяючий бейдж `💎 Delux` (для SuperPremium) або `👑 Delux` (для Delux).
- **29 авторських векторних SVG-аватарок**: колекція персонажів від Волл-стріт Бика і Кібер-Самурая до Короля Лева та Валькірії.
- **27 анімованих VIP-рамок**: унікальні плавні CSS-ефекти сяйва неону, лазерного контуру, лави, льоду, матриці та королівського золота.
- **Два інтерфейси**: «Темний Кібер-Преміум» та «Світлий Необанк».
- **Динамічна зміна іконки**: «Смарагдовий Щит (₴)» та «VIP-Діамант» з миттєвим оновленням логотипу та Favicon вкладки.

## 🚀 Встановлення та запуск

### Вимоги:
- [Node.js](https://nodejs.org/) версії 18.17 або вище.
- npm або yarn.

### Кроки:
1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/ВАШ_НІКНЕЙМ/РЕПОЗИТОРІЙ.git
   cd РЕПОЗИТОРІЙ
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```
   Відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

4. Збірка для продакшну:
   ```bash
   npm run build
   npm start
   ```
